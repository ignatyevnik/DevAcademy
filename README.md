# ДевАкадемия

**Офлайн-учебник по инженерным практикам.** 11 курсов, 261 урок: Git, Linux, сети, SQL, Python, тестирование, Docker, Kubernetes, CI/CD, ИИ-агенты, проектирование.

Работает полностью офлайн (PWA). Прогресс хранится в браузере. Экспорт/импорт прогресса — через JSON.

**Некоммерческий проект.** Любой желающий может пользоваться приложением, получить исходники, форкнуть и адаптировать под свои задачи.

---

## ✨ Возможности

* **11 курсов, 261 урок** — от новичка до Senior в QA и Middle в DevOps/Backend/AI.
* **10 типов заданий**: выбор ответа (single/multiple), текстовый ввод (fill), сопоставление (matching), сортировка (sorting), интерактивные таблицы (table), числовой ответ (number), заполнение пропусков (cloze) и написание кода (code).
* **Полнотекстовый поиск (Ctrl+K)** — ищет не только по названиям курсов, но и по всему содержимому уроков, коду и вариантам ответов.
* **Интервальное повторение (Spaced Repetition)** — алгоритм SM-2, как в Anki. Приложение само напоминает, какие вопросы пора повторить, чтобы знания не выветривались.
* **Личные заметки** — можно вести конспект прямо под каждым шагом урока. Заметки сохраняются и экспортируются вместе с прогрессом.
* **Закладки** — сохранение уроков «на потом».
* **Тёмная и светлая темы** — переключение вручную или автоматически по системным настройкам.
* **Инлайн-код** — выделение `` `команд` `` в тексте красивыми плашками.
* **Экспорт/импорт прогресса** — JSON-файл для переноса обучения на другое устройство.
* **Офлайн-режим (PWA)** — приложение устанавливается на телефон или десктоп и работает без интернета.

## Быстрый старт

### Требования

- **Node.js 20.19+ или 22.12+** — ниже не заработает (Vite 7 требует)
- **npm 10+** (идёт вместе с Node)
- Операционная система: Windows, macOS, Linux

Проверить версию:

```bash
node -v      # v20.19.0 или v22.12.0 и выше
npm -v       # 10.x.x и выше
```

### Установка

```bash
# 1. Клонировать репозиторий (или распаковать архив)
git clone <url> DevAcademy
cd DevAcademy

# 2. Установить зависимости (~400 МБ, 1–3 минуты)
npm install

# 3. Запустить dev-сервер
npm run dev
```

Откройте http://localhost:3000 — приложение готово.

## Запуск

### Dev-режим (разработка)

```bash
npm run dev
```

- Адрес: http://localhost:3000
- Горячая перезагрузка (HMR) при изменении файлов
- **Service Worker отключён** — офлайн-режим не работает в `dev`
- Идеально для разработки контента: правите `src/data/*.ts` — сразу видите

### Production-сборка

```bash
npm run build
```

- Собирает TypeScript (`tsc -b`) и Vite (`vite build`)
- Результат — папка `dist/` (статика: HTML, JS, CSS, иконки, Service Worker)
- **Если `tsc` падает** — сборка не пройдёт. Ошибки типов блокируют релиз

### Preview (проверка production-сборки)

```bash
npm run preview
```

- Адрес: http://localhost:4173
- Обслуживает `dist/` как настоящий сервер
- **Здесь работает PWA и офлайн-режим** — проверяйте его только в `preview`

## Проверка качества

```bash
npm test              # vitest — 61+ тест (валидация контента и логика прогресса)
npm run lint          # eslint
npx tsc -b --noEmit   # только проверка типов, без сборки
```

Перед коммитом — обязательно `npx tsc -b --noEmit && npm test`. Валидация zod и тесты ловят 90% ошибок в контенте (опечатки в `correct`, дубли `id`, забытый `type: 'quiz'`).

## Как выглядят уроки

Уроки — это **TypeScript-объекты**, не отдельные файлы. Весь курс — один файл `src/data/<slug>.ts`. Так проще редактировать, видеть структуру и валидировать.

### Иерархия
```
Course (курс) → Module (модуль) → Lesson (урок) → Step (шаг: теория или задание)
```

### Блоки теории (TextBlock)
| Тип | Поля | Что рендерится |
|---|---|---|
| `p` | `text` | Абзац |
| `h3` | `text` | Подзаголовок |
| `list` | `items: string[]` | Маркированный список |
| `code` | `lang`, `code`, `caption?` | Блок с подсветкой и номерами строк |
| `note` | `text` | Выделенный блок «важно» (зелёная рамка) |
| `table` | `head: string[]`, `rows: string[][]`, `caption?` | Таблица |

*Во всех текстовых полях работает инлайн-код: `` `git commit` ``.*

### Задания (Quiz) — 10 типов

**1. Single choice (один вариант):**
```ts
{ kind: 'single', question: '...', options: [...], correct: ['b'], explanation: '...' }
```

**2. Multiple choice (несколько):**
```ts
{ kind: 'multiple', question: '...', options: [...], correct: ['a', 'b'], partial: true, explanation: '...' }
```

**3. Fill (текстовый ввод):**
```ts
{ kind: 'fill', question: '...', accepted: ['pwd', 'PWD'], placeholder: 'команда', hint: '...', explanation: '...' }
```

**4. Matching (сопоставление):**
```ts
{ kind: 'matching', question: '...', pairs: [{ left: 'ls', right: 'список файлов' }, ...], explanation: '...' }
```
*⚠️ Все значения `right` должны быть уникальны.*

**5. Sorting (сортировка):**
```ts
{ kind: 'sorting', question: '...', items: ['A', 'B', 'C'], correct: ['C', 'A', 'B'], explanation: '...' }
```

**6. Table (таблица с чекбоксами):**
```ts
{ kind: 'table', question: '...', columns: ['Docker', 'VM'], rows: [{ label: 'Делит ядро', correct: ['Docker'] }], explanation: '...' }
```

**7. Number (числовой ответ):**
```ts
{ kind: 'number', question: '...', correct: 254, tolerance: 0, explanation: '...' }
```

**8. Cloze (заполнение пропусков):**
```ts
{ kind: 'cloze', question: '...', text: 'git ____ ____ feature', blanks: [{ accepted: ['switch'], hint: '...' }], explanation: '...' }
```

**9. Code (написание кода):**
```ts
{ kind: 'code', question: '...', starterCode: 'def f():', mustInclude: [{ pattern: 'return', message: 'Нужен return' }], mustNotInclude: [...], explanation: '...' }
```

**10. Title** (псевдо-тип для поиска совпадений в названиях).

## Как добавить урок

1. Откройте файл курса: `src/data/<slug>.ts`
2. В нужном модуле добавьте `lesson` в массив `lessons`.
3. **Проверьте:**
   ```bash
   npx tsc -b --noEmit   # типы
   npm test              # валидация схем
   ```
4. Откройте http://localhost:3000 — урок появится в программе курса.

## Как добавить курс

1. **Создайте** `src/data/<slug>.ts` по образцу `python.ts` (структура `Course` — см. `types.ts`).
2. **Обновите 4 файла:**
   - `src/data/types.ts` — добавьте `icon` в `CourseIcon`
   - `src/data/schemas.ts` — добавьте то же в `z.enum([...])` и в `message`
   - `src/components/CourseIcon.tsx` — добавьте `case` в `switch` с SVG
   - `src/data/index.ts` — импорт + в массив `courses`
3. **Проверьте:** `npx tsc -b --noEmit && npm test`

⚠️ **Самая частая ошибка:** обновить `types.ts`, но забыть `schemas.ts`. TypeScript пропустит, но zod упадёт в рантайме.

## Офлайн-режим (PWA) и Деплой

Приложение работает **полностью офлайн** после первого визита. Все файлы кэшируются Service Worker, контент — часть JS-бандла, прогресс — `localStorage`.

### Как задеплоить на GitHub Pages (бесплатно)

1. В `vite.config.ts` измените `base` на название вашего репозитория: `base: '/DevAcademy/',` (где `DevAcademy` — имя репо).
2. В настройках репозитория на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Закоммитьте изменения и сделайте `git push origin main`.
4. GitHub Actions автоматически соберёт проект и выложит его. Ссылка появится в настройках Pages.

### Проверка офлайн-режима

```bash
npm run build
npm run preview
```
1. Откройте http://localhost:4173
2. F12 → **Application** → **Service Workers** — статус `activated`
3. **Network** → поставьте **Offline**
4. **F5** — приложение загрузится, всё работает (включая поиск, заметки и SRS).
