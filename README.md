# ДевАкадемия

**Офлайн-учебник по инженерным практикам.** 11 курсов, 232 урока: Git, Linux, сети, SQL, Python, тестирование, Docker, Kubernetes, CI/CD, ИИ-агенты, проектирование.

Работает полностью офлайн (PWA). Прогресс хранится в браузере. Экспорт/импорт прогресса — через JSON.

**Некоммерческий проект.** Любой желающий может пользоваться приложением, получить исходники, форкнуть и адаптировать под свои задачи.

## Быстрый старт

### Требования

- **Node.js 20.19+ или 22.12+** — ниже не заработает (Vite 7 требует)
- **npm 10+** (идёт вместе с Node)
- Операционная система: Windows, macOS, Linux

Проверить версию:

```bash
node -v      # v20.19.0 или v22.12.0 и выше
npm -v       # 10.x.x и выше
```

### Установка

```bash
# 1. Клонировать репозиторий (или распаковать архив)
git clone <url> DevAcademy
cd DevAcademy

# 2. Установить зависимости (~400 МБ, 1–3 минуты)
npm install

# 3. Запустить dev-сервер
npm run dev
```

Откройте http://localhost:3000 — приложение готово.

### Что установится (основное)

**Runtime-зависимости (попадают в `dist/`):**

| Пакет | Зачем |
|---|---|
| `react`, `react-dom` | UI-фреймворк |
| `react-router` | Маршрутизация (HashRouter — для PWA/офлайна) |
| `lucide-react` | Иконки |
| `class-variance-authority`, `clsx`, `tailwind-merge` | Утилиты для классов |
| `@radix-ui/react-slot` | Примитив для `asChild` в кнопках/бейджах |
| `sonner` | Тосты (уведомления) |
| `prism-react-renderer` | Подсветка кода |
| `zod` | Валидация контента при загрузке |

**Dev-зависимости (только для разработки, в `dist/` не попадают):**

| Пакет | Зачем |
|---|---|
| `vite`, `@vitejs/plugin-react` | Сборщик и dev-сервер |
| `typescript` | Типы |
| `tailwindcss`, `postcss`, `autoprefixer` | Стили |
| `vite-plugin-pwa` | Service Worker, манифест |
| `eslint` + плагины | Линтер |
| `vitest`, `jsdom`, `@testing-library/react` | Тесты |

Полный список — в `package.json`.

## Запуск

### Dev-режим (разработка)

```bash
npm run dev
```

- Адрес: http://localhost:3000
- Горячая перезагрузка (HMR) при изменении файлов
- **Service Worker отключён** — офлайн-режим не работает в `dev`
- Идеально для разработки контента: правите `src/data/*.ts` — сразу видите

### Production-сборка

```bash
npm run build
```

- Собирает TypeScript (`tsc -b`) и Vite (`vite build`)
- Результат — папка `dist/` (статика: HTML, JS, CSS, иконки, Service Worker)
- **Если `tsc` падает** — сборка не пройдёт. Ошибки типов блокируют релиз

### Preview (проверка production-сборки)

```bash
npm run preview
```

- Адрес: http://localhost:4173
- Обслуживает `dist/` как настоящий сервер
- **Здесь работает PWA и офлайн-режим** — проверяйте его только в `preview`

### Деплой

`dist/` — статика. Разложить можно куда угодно:

- **GitHub Pages** — `dist/` в ветку `gh-pages`
- **Netlify / Vercel / Cloudflare Pages** — подключить репо, build command `npm run build`, output `dist`
- **Nginx** — положить `dist/` в `/var/www/html`, настроить `try_files $uri /index.html`
- **Docker** — nginx:alpine + `COPY dist/ /usr/share/nginx/html`

Важно: `base: './'` в `vite.config.ts` и `HashRouter` — приложение работает в любом подкаталоге, не требует настройки путей.

## Проверка качества

```bash
npm test              # vitest — 55+ тестов
npm run lint          # eslint
npx tsc -b --noEmit   # только проверка типов, без сборки
```

Перед коммитом — обязательно `npx tsc -b --noEmit && npm test`. Валидация zod и тесты ловят 90% ошибок в контенте (опечатки в `correct`, дубли `id`, забытый `type: 'quiz'`).

## Как выглядят уроки

Уроки — это **TypeScript-объекты**, не отдельные файлы. Весь курс — один файл `src/data/<slug>.ts`. Так проще редактировать, видеть структуру и валидировать.

### Иерархия

```
Course (курс)
  └── Module (модуль)
        └── Lesson (урок)
              └── Step (шаг: теория или задание)
```

Пример: `python-basics` → модуль «Основы синтаксиса» → урок «Переменные и типы» → шаг «Проверь себя».

### Урок (Lesson) — минимальная единица навигации

```ts
{
  id: 'py-l1',                    // уникален в пределах модуля
  title: 'Переменные и типы',
  minutes: 15,                    // оценка времени
  steps: [ /* шаги */ ],
}
```

### Шаг (Step) — два типа

**Тип 1: теория**

```ts
{
  id: 'py-l1-s1',
  title: 'Как Python хранит значения',
  type: 'theory',
  blocks: [ /* текстовые блоки */ ],
}
```

**Тип 2: задание**

```ts
{
  id: 'py-l1-s3',
  title: 'Проверь себя',
  type: 'quiz',                   // ← обязателен!
  quiz: { /* задание */ },
}
```

### Блоки теории (TextBlock)

| Тип | Поля | Что рендерится |
|---|---|---|
| `p` | `text` | Абзац |
| `h3` | `text` | Подзаголовок |
| `list` | `items: string[]` | Маркированный список |
| `code` | `lang`, `code`, `caption?` | Блок с подсветкой и номерами строк |
| `note` | `text` | Выделенный блок «важно» (зелёная рамка) |
| `table` | `head: string[]`, `rows: string[][]`, `caption?` | Таблица |

Поддерживаемые `lang` в `code`: `python`, `yaml`, `bash`, `json`, `sql`, `dockerfile`, `ini`, `javascript`, `typescript`, `markup`, `markdown`, `text`. Если нужен новый — добавьте в `LANG_MAP` в `src/components/CodeBlock.tsx`.

### Задания (Quiz) — четыре типа

**Single choice** — один правильный ответ:

```ts
{
  kind: 'single',
  question: 'Что такое Linux?',
  options: [
    { id: 'a', text: 'Дистрибутив' },
    { id: 'b', text: 'Ядро' },
  ],
  correct: ['b'],                // ровно один id
  explanation: 'Linux — это ядро…',
}
```

**Multiple choice** — несколько правильных:

```ts
{
  kind: 'multiple',
  question: 'Какие методы идемпотентны?',
  options: [ /* ... */ ],
  correct: ['a', 'b', 'd'],       // 1+ id
  explanation: '...',
  partial: true,                  // опционально: частичный зачёт (без ложных выборов)
}
```

**Fill** — ввод ответа (текст):

```ts
{
  kind: 'fill',
  question: 'Какая команда покажет текущую директорию?',
  accepted: ['pwd', 'PWD'],       // регистрозависимо, 1+ вариантов
  placeholder: 'команда',
  hint: 'print working directory',
  explanation: 'pwd — print working directory…',
}
```

**Matching** — сопоставление пар:

```ts
{
  kind: 'matching',
  question: 'Сопоставьте команду и действие',
  pairs: [
    { left: 'ls', right: 'Список файлов' },
    { left: 'cd', right: 'Сменить директорию' },
  ],
  explanation: '...',
}
```

⚠️ **Правило `matching`:** все значения `right` должны быть **уникальны**. Иначе один правильный ответ подойдёт к нескольким левым — валидатор не пропустит.

### Как это выглядит в интерфейсе

- **Теория** — текст, списки, блоки кода, заметки, таблицы
- **Тест** — карточка с вопросом, вариантами и кнопкой «Проверить»
- После ответа — результат («Верно!» / «Пока неверно») и объяснение
- Верный ответ — тост «Шаг засчитан», шаг отмечается зелёным в сайдбаре
- Прогресс сохраняется в `localStorage` при каждом действии

## Как добавить урок

1. Откройте файл курса: `src/data/<slug>.ts`
2. В нужном модуле добавьте `lesson` в массив `lessons`:

```ts
{
  id: 'py-l4',                    // уникален в модуле
  title: 'Новый урок',
  minutes: 20,
  steps: [
    {
      id: 'py-l4-s1',
      title: 'Теория',
      type: 'theory',
      blocks: [
        { type: 'p', text: 'Текст…' },
        { type: 'code', lang: 'python', code: `print("hi")` },
      ],
    },
    {
      id: 'py-l4-s2',
      title: 'Проверь себя',
      type: 'quiz',
      quiz: {
        kind: 'single',
        question: 'Вопрос?',
        options: [
          { id: 'a', text: 'Да' },
          { id: 'b', text: 'Нет' },
        ],
        correct: ['a'],
        explanation: 'Потому что…',
      },
    },
  ],
}
```

3. **Проверьте:**

```bash
npx tsc -b --noEmit   # типы
npm test              # валидация схем
```

4. Откройте http://localhost:3000 — урок появится в программе курса.

## Как добавить курс

1. **Создайте** `src/data/<slug>.ts` по образцу `python.ts` (структура `Course` — см. `types.ts`).
2. **Обновите 4 файла:**
   - `src/data/types.ts` — добавьте `icon` в `CourseIcon` (если новая иконка)
   - `src/data/schemas.ts` — добавьте то же в `z.enum([...])` и в `message`
   - `src/components/CourseIcon.tsx` — добавьте `case` в `switch` с SVG
   - `src/data/index.ts` — импорт + в массив `courses`
3. **Опционально** — добавьте в `src/data/tracks.ts` (в нужные треки).
4. **Проверьте:**

```bash
npx tsc -b --noEmit && npm test && npm run dev
```

⚠️ **Самая частая ошибка:** обновить `types.ts`, но забыть `schemas.ts`. TypeScript пропустит, но zod упадёт в рантайме: «icon должен быть: …». Это **двойная защита** — типы проверяют код, схемы проверяют данные.

## Офлайн-режим (PWA)

Приложение работает **полностью офлайн** после первого визита:

- Все файлы (HTML, JS, CSS, иконки) кэшируются Service Worker
- Контент курсов — часть JS-бандла, не грузится с бэкенда
- Прогресс — `localStorage`, никуда не уходит
- Никаких сетевых запросов после установки

**Проверить офлайн:**

```bash
npm run build
npm run preview
```

1. Откройте http://localhost:4173
2. F12 → **Application** → **Service Workers** — статус `activated`
3. **Application** → **Manifest** — «ДевАкадемия», зелёные галочки на иконках
4. **Network** → поставьте **Offline**
5. **F5** — приложение загрузится, всё работает

**Установить как приложение:**

- Chrome/Edge: иконка «Установить» в адресной строке
- Safari (iOS): Поделиться → «На экран «Домой»»
- Android: меню → «Установить приложение»

**Важно:** офлайн-режим **не работает в `npm run dev`** — Service Worker отключён для удобства разработки (`devOptions.enabled: false` в `vite.config.ts`). Проверяйте только через `build && preview`.

### Экспорт/импорт прогресса

Внизу главной — секция «Прогресс обучения»:

- **Скачать** → JSON-файл `dev-academy-progress-YYYY-MM-DD_HH-mm-ss.json` (например, `dev-academy-progress-2025-11-01_14-30-45.json`) — дата и время в **локальном часовом поясе**, чтобы несколько бэкапов за день не перезаписывали друг друга и было видно, какой из них свежее
- **Загрузить** → выбор файла, замена текущего прогресса

Сценарии: смена устройства, бэкап перед очисткой браузера, восстановление после сброса настроек.

Формат JSON:

```json
{
  "app": "dev-academy",
  "version": 1,
  "exported_at": "2025-11-01T12:00:00.000Z",
  "progress": {
    "done": { "python-basics:py-l1-s1": true },
    "lastVisited": {
      "python-basics": { "lessonId": "py-l1", "stepIndex": 2, "ts": 1730000000000 }
    },
    "quizResults": { "python-basics:py-l1-s3": "ok" }
  }
}
```

Загрузка валидирует через zod: не тот `app`, неверная `version`, битый JSON — понятная ошибка, прогресс не меняется. Перед заменой показывается дата экспорта из файла («Файл от 2025-11-01 14:30»), чтобы вы видели, что загружаете.

## Лицензия и использование

**Некоммерческий образовательный проект.** Исходники открыты — любой желающий может:

- **Пользоваться** приложением без ограничений
- **Получить исходники** и запустить локально
- **Форкнуть** и адаптировать под свои задачи (свои курсы, своя тематика, свой бренд)
- **Использовать** как основу для личного или учебного проекта
- **Дополнять** курсами, уроками, новыми типами заданий

Приложение не собирает никаких данных, не отправляет ничего на сервер, не требует регистрации. Прогресс живёт только в вашем браузере.

Если используете в коммерческих целях — проверьте лицензии зависимостей (React, Vite, Tailwind, Prism — все MIT/Apache-2.0, совместимы). Код самого приложения — используйте свободно.

**Обратная связь и предложения:** создавайте issue или PR в репозитории — контент и код открыты для улучшений.
