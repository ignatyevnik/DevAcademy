# Как внести вклад в DevAcademy

Спасибо за интерес к проекту! Мы рады любым улучшениям: от исправления опечаток в тексте до добавления новых курсов и типов заданий. Этот проект существует для сообщества и развивается благодаря таким людям, как вы.

## 🚀 Быстрый старт

1. **Форкните** репозиторий (кнопка *Fork* в правом верхнем углу на GitHub).
2. **Клонируйте** свой форк на локальную машину:
   ```bash
   git clone https://github.com/ВАШ_НИК/DevAcademy.git
   cd DevAcademy
   ```
3. **Установите зависимости** (требуется Node.js версии 20.19+ или 22.12+):
   ```bash
   npm install
   ```
4. **Запустите dev-сервер**:
   ```bash
   npm run dev
   ```
5. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🛠 Что можно улучшить

### Исправление ошибок в контенте
Весь учебный контент хранится в виде TypeScript-объектов в папке `src/data/*.ts`. Если вы нашли опечатку, неточность или устаревшую информацию:
1. Найдите нужный файл (например, `src/data/linux.ts`).
2. Исправьте текст.
3. Запустите `npm run dev`, чтобы проверить изменения в браузере.

### Добавление новых уроков
1. Откройте файл курса (например, `src/data/python.ts`).
2. Найдите нужный модуль и добавьте новый объект `Lesson` в массив `lessons`.
3. **Важно:** после добавления обязательно запустите проверку типов и валидацию данных:
   ```bash
   npx tsc -b --noEmit
   npm test
   ```
   *Валидация (zod) автоматически проверит, что у всех шагов есть поле `type`, что в тестах `correct` ссылается на существующие `options`, и что нет дублей `id`.*

### Добавление нового курса
1. Создайте файл `src/data/ваш-курс.ts` по образцу существующих (например, `git.ts`).
2. Добавьте новую иконку в `src/data/types.ts` (в тип `CourseIcon`).
3. Обновите валидатор в `src/data/schemas.ts` (добавьте иконку в `z.enum`).
4. Отрисуйте иконку в `src/components/CourseIcon.tsx` (добавьте `case` в `switch`).
5. Импортируйте и добавьте курс в массив `courses` в `src/data/index.ts`.
6. Прогоните `npm test` и убедитесь, что всё зелёное.

## 📏 Стандарты кода и контента

* **Код:** TypeScript, ESLint. Перед коммитом запускайте `npm run lint` и `npx tsc -b --noEmit`. Сборка не пройдёт, если есть ошибки типов.
* **Форматирование текста:** 
  * Для выделения команд, переменных или кода прямо в тексте используйте обратные кавычки: `` `git commit` ``. Наш рендерер автоматически превратит это в красивую подсветку.
  * В заданиях типа `matching` (сопоставление) значения в поле `right` должны быть **строго уникальными**. Если два левых элемента имеют одинаковый правильный ответ, объедините их.
  * В таблицах (`table`) не оставляйте пустых строк в `head`. У каждой колонки должно быть название.
* **Коммиты:** Пишите осмысленные сообщения (например, `Add lesson about Docker Volumes`, а не `fix` или `update`).

## 🔀 Как отправить изменения

1. Создайте новую ветку для вашей задачи:
   ```bash
   git checkout -b feature/my-new-lesson
   ```
2. Внесите изменения и закоммитьте их:
   ```bash
   git add .
   git commit -m "feat: add new lesson about Kubernetes Ingress"
   ```
3. Отправьте ветку в свой форк:
   ```bash
   git push origin feature/my-new-lesson
   ```
4. Откройте **Pull Request** в оригинальный репозиторий. Опишите, что вы изменили и зачем. Мы постараемся рассмотреть его как можно быстрее.
